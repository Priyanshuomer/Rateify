# Welcome to the Project

## Development

To run the project locally, you need Node.js and npm. You can install Node.js using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <your-repository-url>
cd <repository-name>
npm install
npm run dev
```
